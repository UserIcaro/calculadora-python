# 🧮 Calculadora em Python

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![Status](https://img.shields.io/badge/status-em%20evolu%C3%A7%C3%A3o-yellow)

> Calculadora de terminal com menu interativo, feita para praticar lógica de programação em Python.

## 🚀 Funcionalidades

- ➕ **Operações básicas:** soma, subtração, multiplicação e divisão
- 🛡️ **Validação de entrada:** não quebra se o usuário digitar letras
- 🚫 **Proteção contra erros:** bloqueia divisão por zero
- 🔄 **Menu contínuo:** repete até o usuário escolher sair

## 👀 Como fica rodando

```
=========================
1. Adição          [+]
2. Subtração       [-]
3. Multiplicação   [*]
4. Divisão         [/]
5. Sair
=========================
Escolha um número: 1
Adição
1º número: 10
2º número: 5
Resultado: 15.0
```

## 💻 Como executar

1. Instale o [Python 3](https://www.python.org/downloads/)
2. Baixe o arquivo `calculadora.py`
3. No terminal, rode:

```bash
python calculadora.py
```

## 📚 O que aprendi

- Laços `while`, `break` e `continue`
