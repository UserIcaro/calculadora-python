# Calculadora em Python

Calculadora de terminal feita em Python, com menu interativo.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Validação de entrada (não quebra se digitar letras)
- Bloqueio de divisão por zero
- Menu que repete até o usuário escolher sair

## Como rodar

1. Tenha o Python 3 instalado
2. Baixe o arquivo `calculadora.py`
3. No terminal, rode:
```
python calculadora.py
```
## O que aprendi

- Funções, laços `while`, `break` e `continue`
- Tratamento de erros com `try/except`
