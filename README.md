# 🧮 Calculadora em Python

> Uma calculadora interativa de terminal desenvolvida em Python, focada em simplicidade, validação de dados e robustez contra erros de entrada.

---

## 🚀 Funcionalidades

- ➕ **Operações Básicas**: Soma, subtracção, multiplicação e divisão.
- 🛡️ **Validação de Entrada**: Tratamento para evitar travamentos ao digitar letras ou símbolos inválidos.
- 🚫 **Protecção contra Erros**: Bloqueio automático de divisão por zero.
- 🔄 **Fluxo Contínuo**: Menu interativo em ciclo (*loop*) até o utilizador decidir sair.
